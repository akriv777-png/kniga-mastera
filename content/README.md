# Тексты и данные книг

Ассистент может менять содержимое здесь, не трогая код приложения.

## Интерфейс Mini App

- `content/ui.json` — названия, подсказки и ошибки стартового экрана
  (выбор режима «Игрок» / «Мастер», поля кода комнаты).
- `content/api.json` — необязательный адрес сервера проверки
  (`auth_api`). Обычно его передаёт бот параметром `?api=`.

## Книга Мастера

Игровой текст и таблицы лежат отдельно от логики экрана:

- `data/*.js` — заклинания, чудовища, предметы, карты, таблицы
- `content.js` — дополнительные случайные таблицы и существа книги
- модули в корне репозитория (`builder.js`, `campaign.js`, `combat.js` и другие)

Точка входа книги: `master.html`.

## Книга Игрока

- `player/pd-spells.js`, `player/pd-items.js`, `player/pd-art.js`, `player/pdata.js` / `player/pdl.js`
- точка входа: `player/index.html`

Весь прежний контент сохранён. Новые фразы для бота и стартового
экрана добавляйте в `ui.json`.
